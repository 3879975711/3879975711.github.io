MC 启动器

Windows 下的 Minecraft 启动器。双击运行，自动打开浏览器操作。

下载

下载启动器（58 KB） 使用方法

单个 exe 文件，不需要安装。Windows 10 / 11 自带运行环境。

功能

  • 下载任意版本的 Minecraft，包括正式版和快照：客户端、依赖库、资源文件
  • 一键启动游戏，自动匹配所需 Java，缺失时可以自动下载
  • 微软账号正版登录，登录一次后自动保持
  • 没登录也能用离线模式，自己填写玩家名
  • 国内默认走 BMCLAPI 镜像，也可以切换 Mojang 官方源

使用方法

  • 双击 MCLauncher.exe，程序在后台运行并打开浏览器
  • 左侧选择版本，点“下载并安装”，等待下载完成
  • 点“启动游戏”。需要正版时点右上角“登录微软账号”
  • 游戏数据、配置、Java 都保存在启动器所在目录（.minecraft 文件夹）
  • 关闭页面不会退出程序；要退出请点页面底部的“退出启动器”

如果浏览器没有自动打开，手动访问 http://127.0.0.1:4434

说明

  • 只监听本机 127.0.0.1，外部设备无法访问
  • 正版登录需要该微软账号已拥有 Minecraft，登录信息由微软官方接口处理
  • 内存占用约 40 MB，程序体积 58 KB，不会在后台常驻其他进程
需要 Java 运行游戏。没有 Java 时，在设置里点“下载 Java”即可。端口固定 4434，被占用时程序会提示。
